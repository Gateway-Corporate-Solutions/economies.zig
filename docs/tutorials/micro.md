# Tutorial: clearing a two-good exchange

Define each agent's Cobb-Douglas share and endowment, call `micro.walrasPrice`, and verify `walrasExcessX` is below the documented tolerance. Positive prices and endowments are mandatory. The solver uses the public bisection utility and never mutates agents.

Run `./zigw build examples`, then execute the compiled `micro-walras` artifact through a local run step or copy the example into an application importing `economies`.
